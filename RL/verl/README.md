# Bundled verl Source

This directory contains the verl implementation used by the Open-o3-Video-v2 agent loop. Project-specific additions live in custom_agent_loops/, custom_datasets/, custom_rewards/, custom_tools/, and examples/video_tools/config/.

For the upstream framework, documentation, and current releases, see [verl](https://github.com/volcengine/verl). Its Apache-2.0 [license](LICENSE) and [notice](Notice.txt) are retained here.
